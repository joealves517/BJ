# Blackjack Assistant (Infinite Fun 21)

A mobile-optimized Blackjack assistant for the "Infinite Fun 21" variant. 

## Features
- Optimal strategy (modified Spanish 21/Fun 21)
- Card counting (Katarina Walker system)
- Bet sizing (Kelly Criterion)
- Bankroll management
- English UI (Mobile-First)

## Live Demo
[https://joealves517.github.io/BJ/](https://joealves517.github.io/BJ/)

## Local Development
1. `cd blackjack-assistant`
2. `npm install`
3. `npm run dev`

## Deployment
`npm run deploy` inside the `blackjack-assistant` directory.
